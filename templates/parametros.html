Concepto 02

Parámetros y argumentos

Haz que tus funciones reciban datos y devuelvan resultados.

Parámetro vs Argumento

Parámetro

Variable que se declara en la definición de la función. Actúa como un marcador de posición.

Argumento

Valor real que se pasa cuando se llama a la función.

def sumar(a, b):  # a y b son parámetros
    return a + b

sumar(3, 5)      # 3 y 5 son argumentos
Definición def saludar(nombre):
↓ parámetro ↓
Llamada saludar("Ana")
↓ argumento ↓
Resultado ¡Hola, Ana!

Tipos de parámetros

Posicionales

El orden importa. El primer argumento va al primer parámetro.

def restar(a, b): return a - b
restar(10, 3) → 7
Por defecto

Valor predefinido si no se envía el argumento.

def saludar(n, s="Hola"): ...
saludar("Ana") → Hola, Ana!
Por nombre

Se pasan indicando el nombre del parámetro. No importa el orden.

saludar(nombre="Ana", saludo="Hey")
